⛳ 이 프로그램은?
골프 라운딩 후 정확한 정산을 위해 제작된 AI 자동 계산기입니다. 스코어카드 이미지를 업로드하면 AI가 자동으로 인식하고 홀별 득실 및 배판·니어리스트까지 계산합니다.
🎮 골프존 스코어카드 업로드 방법
• 골프존·스크린골프 이미지 1장에는 2명이 포함됩니다
• 4명 라운드: 카드1(플레이어1·2) + 카드2(플레이어3·4) 총 2장 업로드
• 2장을 한 번에 AI에 보내므로 비용 절감 (~36원)
② AI 분석 및 점수 확인
• AI가 이미지를 2단계로 분석 (OCR → 타수 변환)
• 분석 후 인식 점수와 원본 이미지를 나란히 비교하세요
• 합계 불일치 시 해당 홀 점수를 직접 수정 가능
• 플레이어 이름도 수정 가능
🎯 Par3 니어리스트
• Par3 홀 아래에 🎯 니어리스트 버튼이 표시됩니다
• 핀에 가장 가깝게 붙인 플레이어를 클릭하면 선택
• 수령자는 나머지 플레이어에게 각 1타 금액을 받습니다
④ 정산 결과
• 홀별 정산 — 매 홀마다 플레이어 간 득실 계산
• 전반/후반/전체 결산 — 구간별 손익
• 출발 원금 입력 시 — 홀별 자산 변화 추적
• 돈의 흐름 — 누가 누구에게 얼마를 내는지 시각화
⚠️ 주의사항
• 이미지 기반 인식이라 오류가 발생할 수 있습니다 — 원본 이미지와 반드시 비교 후 수동 수정하세요
• AI API 사용으로 분석 1회당 약 33~36원 비용이 발생합니다
